# Same old me, brand-new portfolio stack

Since the last time I really updated my portfolio a lot has changed. The "last commit" on GitHub is a little deceiving, in reality it's been 5+ years since I initially published my portfolio written in React, and in the world of Frontend that's a lifetime. So much has changed not only for the ecosystem but in my skill set as well, and I wanted to write a short blog post to talk about what I've built now and how that differs from the previous version.

## Decisions made

To say that this website is overengineered would be an understatement, but what would a portfolio be if it didn't showcase some of the skills that I've developed? So lets talk mode about what's going on under the hood. If you want a [TL;DR](#tldr) ill be sure to include that at the bottom that you can skip to

### Tanstack Router

Tanstack has been taking the React world by storm as I'm sure many of you are aware, so I won't spend any time explaining their history. Setup was super painless and while the documentation didn't feel as familiar as the Tanstack Query ones, the robust set of guides made my simple implementation a breeze. There has been some hesitancy in the industry to adopt this router over other like React Router due to "maturity", and while I won't recommend you rip out your existing application router I can recommend this for any new projects you're looking to start.
